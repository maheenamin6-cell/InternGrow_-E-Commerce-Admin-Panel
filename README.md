# Ridgeline Admin Panel

An e-commerce admin dashboard (Shopify/WooCommerce style) built with React, Recharts, and lucide-react.

## Setup

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Build

```bash
npm run build
```

Outputs a production build to `dist/`.

## Structure

- `src/AdminPanel.jsx` — the entire admin panel (single component, all pages, mock data)
- `src/main.jsx` — React entry point
